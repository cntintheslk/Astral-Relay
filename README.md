Astral Relay — Discord Automation & Infrastructure Bot

Astral Relay is a modular, multi-purpose Discord bot designed to support role-play communities, gaming servers, and administrative teams.
It provides automated registration flows, LOA handling, moderation tools, changelog broadcasting, and a flexible command system for both global and guild-specific features.

Features

Registration System

Slash command–based registration (/register)

Automatic role assignment & rank approval workflow

R4/R5 ranks require moderator/admin approval

Approval dashboard using reactions

Blacklisted roles & verification safeguards

Full Discord embed-based communication


Admin & Developer Tools

/setup guided configuration

Module toggling

Changelog broadcasting to dedicated channels

GitHub integration: automatic changelog posting on new releases

Developer-only commands locked by role


Server Utility Commands

Role management

Information lookups

Configurable autoroles

Server diagnostics & logging
